# TP-Link front/back strip panels — V10

Three locally generated companion panels, independently constructed from
primitives. These are **not** the shaped rear cover or front retaining caps.
The matching shelf is not distributed here because of its source restrictions.

| Variant | Bambu Studio project | STL |
| --- | --- | --- |
| Plain | [plain.3mf](plain.3mf) | [plain.stl](plain.stl) |
| Lettered | [lettered.3mf](lettered.3mf) | [lettered.stl](lettered.stl) |
| Vented | [vented.3mf](vented.3mf) | [vented.stl](vented.stl) |

- Size: 268 × 30 × 2 mm; raised lettering reaches 2.6 mm.
- Four 9.5 mm rounded-square openings, two per end.
- Horizontal hole-column span: 238.5 mm; centers at X=−119.25/+119.25 mm.
- Vertical hole pitch: 15.9 mm; centers at Y=7.05/22.95 mm, leaving 6.4 mm
  between apertures. Both openings start 10 mm from their external panel end.
- V10 is 2 mm shorter than the original 270 mm design: 1 mm per end, with
  complete end mounting patterns translated inward, not scaled.

Print the chosen style twice if both front and rear strips are needed. Supplied
P2S/PETG projects are flat and diagonal with supports/brim disabled.
**Unprinted V10:** structural checks passed; Preview and physical fit pending.
Verify your actual rack dimensions; this is not a universal 10-inch standard.

The reviewed original generator uses rounded rectangles, vent cuts and DejaVu
Sans text; it imports no upstream mesh. No font files are included. The
generation history is not included in this clean export; the supplied STL/3MF
files are the current artifacts, not a claim of a reproducible panel build here.

MakerWorld compatibility reference: [Benjamin Kott's Modular 10-inch Server
Rack, 1452571](https://makerworld.com/en/models/1452571-modular-10-server-rack).
